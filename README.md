# The Urban Platter 🍽️

A modern, responsive restaurant website built using HTML, CSS, JavaScript, and Bootstrap.

## 🌐 Live Demo
https://theurbanplatter.netlify.app

## ✨ Features
- Modern and responsive restaurant design
- Attractive hero section
- About and restaurant information
- Food menu and chef's specials
- Image gallery
- Table reservation form
- Contact section
- WhatsApp contact button

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- Bootstrap 4.5.2
